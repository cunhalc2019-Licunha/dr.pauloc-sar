# Dr. Paulo César, O PC — Site

Site institucional (HTML + CSS + JS puro, sem dependências).

## Estrutura
- `index.html` — página completa
- `img/pc-hero.png` — foto recortada da abertura
- `img/aviacao-*.jpg` — fotos do bloco de aviação

O número do WhatsApp fica em uma única linha do `index.html` (procure por `const WHATSAPP`).

As demais fotos, logos e vídeos são carregados direto de agaleradrpc.com.br e do YouTube.

## Publicar no GitHub Pages
1. No repositório, vá em **Settings → Pages**.
2. Em *Source*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Salve. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
